Exponential Disk

The disk density profile is

\[\rho(R, z) \propto \exp\!\Big(-\frac{|z|}{h_z} - \frac{R}{h_R}\Big),\]

optionally with a central hole (suppressed density for $R < R_\mathrm{hole}$).

Example

MaxRadius defaults to 5 * ScaleRadius + HoleRadius, and MaxHeight defaults to MaxRadius. The extra HoleRadius keeps the outer tail of a disc with a central hole inside the sampling box.

See ExponentialDisc and generate(::ExponentialDisc) in the Library reference for full signatures and keyword arguments.

With a rotation curve

Pass RotationCurve = (radii, velocities) to assign realistic disk velocities:

rc_r = [0.5, 1.0, 2.0, 4.0, 6.0] .* u"kpc"
rc_v = [50.0, 100.0, 150.0, 200.0, 220.0] .* u"km/s"
particles = generate(config; RotationCurve = (rc_r, rc_v))

The interpolation uses Dierckx.Spline1D with keyword arguments k (spline degree, default 2) and bc (boundary condition, default "nearest"). Set rotational_ratio (default 0.9) to mix in a random isotropic component.
