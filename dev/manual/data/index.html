Data

AstroIC ships with CSV / DAT files from a number of observational surveys so that you can drive simulations directly from published measurements.

Milky Way rotation curves

Three independent measurements of the Milky Way rotation curve are bundled:

FunctionReference
load_MW_RC_Eilers2019Eilers+ (2019), ApJ 871, 120
load_MW_RC_Mroz2019Mróz+ (2019), ApJ 870, L10
load_MW_RC_DS_W21Wang+ (2021), comparing CDM / QUMOND / MOG fits
load_MW_RC_stddev_W21Wang+ (2021) standard-deviation table
using AstroIC
df_eilers = load_MW_RC_Eilers2019()
df_mroz   = load_MW_RC_Mroz2019()
df_w21    = load_MW_RC_DS_W21()
df_w21σ   = load_MW_RC_stddev_W21()

See load_MW_RC_Eilers2019, load_MW_RC_Mroz2019, load_MW_RC_stddev_W21 and load_MW_RC_DS_W21 in the Library reference for full signatures.

Massive dwarf galaxy rotation curves (Cooke 2022)

Six massive dwarf rotation-curve decompositions are bundled (Cooke 2022, MNRAS 512, 1012):

using AstroIC
co  = load_massive_dwarf_CO_RC("NGC1035")        # CO gas contribution
dm  = load_massive_dwarf_DM_RC("NGC1035")        # dark matter
baryon = load_massive_dwarf_Baryon_RC("NGC1035") # total baryonic

See load_massive_dwarf_CO_RC, load_massive_dwarf_DM_RC and load_massive_dwarf_Baryon_RC in the Library reference for full signatures.
