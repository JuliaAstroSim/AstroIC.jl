Package Guide

Installation

From the Julia REPL, type ] to enter the Pkg REPL mode and run

pkg> add AstroIC

or add from git repository:

pkg> add https://github.com/JuliaAstroSim/AstroIC.jl

Test the package by

pkg> test AstroIC

Basic usage

The package follows a two-step pattern: first build an immutable config struct describing the system, then call the generate dispatcher to materialize particles.

julia> using AstroIC
julia> using PhysicalParticles, UnitfulAstroERROR: ArgumentError: Package PhysicalParticles not found in current path, maybe you meant `import/using .PhysicalParticles`.
- Otherwise, run `import Pkg; Pkg.add("PhysicalParticles")` to install the PhysicalParticles package.
julia> config = PlummerStarCluster(
           NumSamples   = 1000,
           VirialRadius = 0.010u"kpc",
           TotalMass    = 1.0e5u"Msun",
       )ERROR: LoadError: ArgumentError: Symbol `kpc` was found in the globally registered unit module UnitfulAstro
but was not in the provided list of unit modules Unitful, PhysicalParticles.

(Consider `using UnitfulAstro` in your module if you are using `@u_str`?)
in expression starting at REPL[3]:3
julia> data = generate(config; MaxRadius = 0.050u"kpc")ERROR: LoadError: ArgumentError: Symbol `kpc` was found in the globally registered unit module UnitfulAstro
but was not in the provided list of unit modules Unitful, PhysicalParticles.

(Consider `using UnitfulAstro` in your module if you are using `@u_str`?)
in expression starting at REPL[4]:1
julia> length(data)ERROR: UndefVarError: `data` not defined in `Main`
Suggestion: check for spelling errors or missing imports.

By default, particles are returned in uAstro units (kpc, kpc/Gyr, Msun). Pass uSI to get SI units instead:

data_si = generate(config, uSI; MaxRadius = 0.050u"kpc")

Composing a galaxy

The typical workflow is to generate each component separately and concatenate them into a single particle array:

julia> using AstroIC
julia> using PhysicalParticles, UnitfulAstroERROR: ArgumentError: Package PhysicalParticles not found in current path, maybe you meant `import/using .PhysicalParticles`.
- Otherwise, run `import Pkg; Pkg.add("PhysicalParticles")` to install the PhysicalParticles package.
julia> bulge = generate(Bulge(; NumSamples = 1000, TotalMass = 8.57u"Msun",
                               ScaleRadius = 0.075u"kpc", CutRadius = 2.1u"kpc",
                               q = 0.5, α = 1.8))ERROR: LoadError: ArgumentError: Symbol `Msun` was found in the globally registered unit module UnitfulAstro
but was not in the provided list of unit modules Unitful, PhysicalParticles.

(Consider `using UnitfulAstro` in your module if you are using `@u_str`?)
in expression starting at REPL[3]:1
julia> disc = generate(ExponentialDisc(; NumSamples = 5000, TotalMass = 1.0e10u"Msun",
                                         ScaleRadius = 2.0u"kpc", ScaleHeight = 0.02u"kpc"))ERROR: LoadError: ArgumentError: Symbol `Msun` was found in the globally registered unit module UnitfulAstro
but was not in the provided list of unit modules Unitful, PhysicalParticles.

(Consider `using UnitfulAstro` in your module if you are using `@u_str`?)
in expression starting at REPL[4]:1
julia> # Concatenate into a single system
       galaxy = vcat(bulge, disc)ERROR: UndefVarError: `bulge` not defined in `Main`

julia> length(galaxy)ERROR: UndefVarError: `galaxy` not defined in `Main`

bulge and disc are StructArrays with compatible schemas, so vcat / append! work out of the box.
