Solar System

solarsystem returns the eight planets plus the Sun at a given date in SI units. Positions are computed via AstroLib.jl's helio (heliocentric coordinates), velocities are derived from a one-second finite difference.

See solarsystem in the Library reference for the full signature (accepts either a DateTime or a Julian day number).

You can also pass a Julian date directly:

using AstroIC
using Dates

particles = solarsystem(jdcnv(DateTime(2024, 1, 1)))
