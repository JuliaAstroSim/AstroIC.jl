Gas Cloud

A simple SPH gas cloud sampled on a Cartesian grid clipped to a sphere of radius R. Velocities are drawn from a Maxwell–Boltzmann distribution at temperature T.

Example

julia> using AstroIC
julia> using Unitful, UnitfulAstro, PhysicalConstants
julia> config = GasCloud(
           collection   = GAS,
           Radius       = 20u"kpc",
           rho0         = 1250u"Msun/kpc^3",
           T            = 300u"K",
           ParticleMass = Constant().m_p,
