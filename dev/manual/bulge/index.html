Bulge

The bulge density profile is

\[\rho(R, z) \propto \frac{\exp\!\big(-r'^2 / r_\mathrm{cut}^2\big)}{(1 + r' / r_s)^\alpha}, \quad r' = \sqrt{R^2 + (z / q)^2},\]

with axis ratio q (oblate for q < 1) and inner slope α.
